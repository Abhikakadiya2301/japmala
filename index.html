How counting works

Automatic mode adds exactly one Jap whenever the audio file finishes playing. For accurate automatic counts, your clip must contain exactly one complete mantra recitation. Use the +1 Jap button when chanting yourself or playing a song containing several repetitions. If playback is interrupted, an incomplete repetition is not counted. Counts are stored locally in this browser.
